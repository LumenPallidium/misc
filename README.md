## disentanglement

Experiments on disentangled representation learning and self-representation. I had the idea that maybe a "self-representation" could be used to disentangle ones internal model. The experiment consists of an autoencoder that is trying to reconstruct sparsely generated vectors. The vectors are generated by either tensor products of small normally distributed vectors or by fixed upscaling matrices acting on small vectors.

As a baseline, (FactorVAE)[https://arxiv.org/abs/1802.05983] is implemented. The "self-compressing" autoencoder is as follows. The inputs $x$ are compressed to a latent state $z$ and then reconstructed as $\hat x$, as in a standard autoencoder. However, there is a further compression of $z$ with $r$ (as an example, in the experiments dim($z$) is 64 while dim($r$) is 16). This is the "self-compression" and it is trained like an autoencoder by using it to reconstruct $z$ as $\hat z$. In the null case, it ends here and the system is just one with a superflous autoencoder. However in the "self-representing" case, there is a small term encouraging the latent $z$ to be more like $\hat z$, in proportion to $|z - \hat z|^2$. In other words, the representation $z$ becomes more like $\hat z$ if they are similar, so that it becomes more compressible.

Interestingly, the null model and the "self-compressing" one have similar losses at the end, but the self-compressing one is far more compressible (note, in both of them the network is trained to compress $z$, it's only that in the null case $z$ is not made to be more like $\hat z$). As it turns out, this does not lead to disentanglement. The self-compressing system is more entangled, which is not too surprising.

Entanglement is measure using total correlation $\text{KL}(q(z)|| \prod_i q_i(z_i))$ where $q(z)$ is the distribution of $z$ and $q_i(z_i)$ is marginal the distribution of its components. I estimated these via histograms composed with vector quantization, which partially avoided the curse of dimensionality.
